01 · 소스 & 마스크

파트 준비 · 조립 가이드 (수동)
  1. 아래 원본 교체로 내 PNG/JPG를 열어. 이미지와 오디오는 로컬에서만 처리하며 서버에 업로드하지 않아.
  2. 편집 역할을 선택하고 아래 프롬프트를 복사해 원하는 이미지 도구에서 직접 준비해. 자동 분할·외부 이미지 API 호출이 아니야.
  3. 원본과 동일한 인물·색·정면 자세·캔버스 크기·위치를 유지해. 투명 PNG 권장. 크로마 배경은 파트 가져오기 전에 외부 편집기에서 제거해. JPG에는 투명도가 없어.
  4. 가려진 머리 뿌리·목·옷의 연결 재료는 직접 그리거나 준비해야 해. 숨은 부분 복원이나 정밀 자동 정렬을 보장하지 않아.
  5. 역할 선택 → 파트 교체 → 기존 폴리곤 꼭짓점/좌표와 레이어 순서(큰 값이 앞)를 조정 → 이동·배율 적용. 작은 이미지는 영역에 맞추는 단순 맞춤이며 보정된 자동 정렬이 아니야.
  6. 중립과 최대 포즈에서 겹침·빈틈을 확인하고 편집 프로젝트 JSON으로 저장해. 오디오는 저장하지 않아.

복사가 안 되면 텍스트를 선택해 직접 복사해.

꼭짓점을 드래그하거나 아래 정규화 좌표를 편집해. 원본 교체 후 구도가 다르면 마스크 조정이 필요해.

교체 파트에만 적용. 작은 이미지는 기존 폴리곤에 잘려. 이동 후 필요하면 마스크도 조정해. X/Y 0, 배율 1은 기본 맞춤.

로컬 샘플 준비 중…

수동 분리 · 머리 ±12° / 몸 ±6° 초안. 최대 각도·목 연결 미검증. 샘플 눈·입은 실제 표정 텍스처, 일반 교체 원화는 변형 근사. AI 분리 / moc3 아님.

02 · 포즈 & 물리

로컬 오디오 · 진폭 립싱크

파일 선택 후 재생해.

소리가 나오는 재생이야. 음소 정렬·마이크·TTS가 아닌 진폭 기반 입 열기. 최대 20MB / 120초 / 1~2채널, 브라우저 지원 형식. 로컬 디코딩(24kHz), 디코딩 후 길이 검사. 음소거 기능 없음. 운영체제 음량을 확인해. 파일은 저장·업로드하지 않아.

03 · 저장

원본 / 참고 시트

업로드·외부 키 불필요. 제공자 허락으로 샘플 포함 포크·빌드 공개 가능. 코드 Apache-2.0은 아트에 자동 적용되지 않으며 별도 상업 이용·재배포 허락은 아님. 배포 시 캐릭터 NOTICE와 라이선스 고지 동봉.
