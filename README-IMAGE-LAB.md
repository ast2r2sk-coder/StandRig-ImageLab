# Image Lab — PSD 없는 StandRig 로컬 실험판

## 바로 실행

아래 개발 명령으로 생성한 `Image-Lab.html`을 데스크톱 Chrome에서 열면 된다. 생성된 HTML 실행에는 서버, PSD, API 키, 설치 과정이 필요 없다. HTML 안에 사용자 제공 샘플 이미지와 실행 코드가 포함된다. 메신저 내부 미리보기 대신 다운로드한 파일을 브라우저로 연다. 모바일 파일 열기·다운로드는 OS별 추가 확인이 필요하다.

제공자가 샘플 이미지를 이 공개 포크와 해당 빌드에 포함한 공개 배포를 허락했다. 이는 제3자에게 아트의 별도 상업 이용·재배포 라이선스를 부여하는 것이 아니다. [캐릭터 고지](assets/character/NOTICE.md)를 확인한다. Image Lab은 사용자가 입력한 이미지·프로젝트를 자동 업로드하지 않지만, 저장한 HTML·프로젝트 JSON·이미지 포함 JSON·PNG에는 이미지가 들어갈 수 있다. 직접 공개하는 파일에는 개인정보나 별도 권한이 없는 교체 이미지가 없는지 확인한다. 편집 작업은 메모리에만 있으므로 종료/새로고침 전에 프로젝트 JSON을 저장한다.

## 조작

1. 중앙 `재생`: 자동 머리 움직임, 몸 기울기, 깜빡임, 머리카락 위치의 스프링 변형. `일시정지`는 현재 화면과 물리를 멈춘다.
2. 오른쪽 머리/몸 X Y Z 슬라이더: 방향·기울기의 2D 근사 변형. 슬라이더 조작은 자동 재생을 멈춘다. `중립 / 초기화`로 포즈를 되돌린다.
3. `포인터`: 포인터 위치로 머리 X/Y를 제어한다. 재생 중 자동 동작과 함께 사용하지 않는 편이 좋다.
4. `얼굴 확대`: 얼굴/상반신을 확대한다. `경계`는 파트의 경계를 표시한다.
5. 오른쪽 스프링 체크박스, 강성/감쇠: 실제 StandRig 물리 출력을 공유 변형 격자의 머리카락 영역에 적용한다. 다른 레이어와 동일한 연속 좌표계를 유지하여 잘린 조각이 벌어지는 것을 방지한다.

## 나중에 원화 바꾸기

- `원본 교체`에서 PNG/JPG 선택. 정규화된 마스크 좌표와 리그 설정은 유지된다.
- 원본 교체 시 샘플 전용 민트색 머리카락 판별은 해제된다. 구도·얼굴 위치·비율이 다르면 마스크를 조정해야 한다. 임의 캐릭터를 자동으로 이해하는 AI 분리가 아니다.
- 마젠타 아닌 배경은 `키 색상`을 직접 지정하거나 마젠타 제거 체크를 끈다. 복잡한 배경은 미리 투명 PNG로 준비하는 편이 좋다.
- 왼쪽 역할 선택 → 마스크 꼭짓점 드래그 또는 정규화 좌표 JSON 수정 → 좌표 적용.
- `선택 파트 PNG/JPG 교체`: 현재 파트 영역에 새 이미지를 배치한다. 투명 PNG 권장. JPG는 투명도를 지원하지 않는다.
- `파트 PNG 저장`으로 내보낸 전체 스테이지 PNG는 같은 크기일 때 원래 좌표 그대로 재입력된다. 작은 별도 PNG는 선택 영역 크기에 맞춰 배치된다.
- `파트 원본 복원`: 해당 파트의 대체 이미지만 제거한다. 원본 이미지 전체를 되돌리는 버튼은 아니다.

## 저장 종류

- `편집 프로젝트 JSON`: 원본, 교체 파트, 마스크, 설정, 현재 포즈를 포함. Image Lab의 `프로젝트 열기`로 다시 편집.
- `StandRig 이미지 포함 JSON`: 실제 StandRig RigDocument. 표준 코어 validator 오류 0 확인. root/시선/입 형태 표준 파라미터 누락 경고 5개는 남아 있다. 네이티브 import 화면 전체 왕복 및 Connect 호환은 별도 미검증.
- `현재 화면 PNG`: 현재 렌더 결과.
- Cubism `.moc3` / `.cmo3`, 얼굴 추적, 음성 립싱크는 지원하지 않는다.

## 현재 품질과 한계

이 공개 포크는 **검토된 복원 스냅샷의 이미지 기반 로컬 실험판**이다. 공개 준비는 문구·권리 고지 정리이며 리깅이나 복원 품질을 개선한 버전이 아니다. 고품질 Live2D 모델 완성 또는 Model Freeze가 아니며 Cubism `.moc3` / `.cmo3`를 생성하지 않는다. 아래 기존 검증 기록은 복원본의 기록이며 이번 공개 준비에서 새 브라우저 시각 QA를 수행했다는 뜻이 아니다.

- 정면 JPG를 색상 키와 수동 폴리곤으로 분리하고 실제 StandRig의 연속 변형 격자로 구동한다. 숨은 신체·옷·머리카락을 AI로 복원하지 않았다.
- 새 표정 시트의 실제 반쯤/완전히 닫힌 눈과 A/E/O 입을 추출해 네이티브 이미지 레이어로 적용한다. 좌우 눈은 독립 제어하고 `입 형태`는 E(-1)/A(0)/O(1), `입 열기`는 별도로 조절한다. 중립은 원본 그림을 유지한다. 원본 교체 또는 해당 파트 교체 시 샘플 전용 표정 레이어를 사용하지 않는다.
- 머리 방향 시트의 원근 차이를 참고한 2D 차등 변형을 공유 격자에 추가했다. 정밀 실측·3D 복원은 아니며 새 소재 적용 후 실제 브라우저 시각 검수는 아직 필요하다. `head-underlay.jpg`와 `body-underlay.jpg`는 정렬이 검증되지 않아 보관만 하며 런타임에서 사용하지 않는다. 가려진 신체가 복원된 모델이 아니다.
- 얼굴 X ±12, Y ±8, Z ±8 / 몸 X ±6, Y ±4, Z ±4는 슬라이더의 초안 값이다. 실제 3D 회전각을 정밀하게 재현한다는 뜻이 아니다. 넓은 측면 회전·뒤돌기·고개 상하의 독립 참조 검증은 미완료다.
- 샘플 표정은 실제 눈/입 내부 텍스처를 사용하지만 음성 립싱크는 없다. 일반 원본/교체 파트는 기존 세로 축소·늘리기 근사를 유지한다. 눈/입 아래는 인접 피부색 채움이며 피부 경계와 중간 표정 크로스페이드 잔상은 추가 시각 검수 대상이다. 이전 프로젝트의 마스크는 자동 수정하지 않는다.
- JPEG 배경 경계의 보라색 잔색, 확대 시 피부 패치 경계, 격자 렌더의 얇은 삼각형 선이 남을 수 있다.
- 최대 복합 머리 포즈의 큰 가슴/목 구멍은 수정 후 실제 스크린샷으로 확인했지만, 모든 6축 조합의 미술적 완성도를 보증하지 않는다.
- 브라우저 성능은 장치에 따라 다르며 FPS 보증은 없다. 검증은 데스크톱 Chrome과 390px 모바일 뷰포트에서 수행했다.
- 파일당 원본 최대 8MB, 4096px/12MP 입력 제한, 편집 이미지 최대 변 1536px 정규화. 작업 렌더는 높이 최대 900px. 프로젝트 JSON 최대 40MB.

## 개발 실행

프로젝트를 clone한 폴더에서 실행한다.

```sh
npm ci
npm run build
npm run dev
```

`http://127.0.0.1:5181/image-lab.html`을 연다. Image Lab은 기존 StandRig 백엔드 서비스를 필요로 하지 않는다. 사용자 제공 샘플은 `assets/character/`에 포함되어 공개 소스와 함께 내려온다. 제공자의 공개 허락은 포함된 샘플에 관한 것이며, 사용자가 교체한 이미지의 공개 권한까지 보장하지 않는다.

단일 오프라인 HTML을 재생성하려면 빌드 후 `node scripts/package-image-lab.mjs`를 실행한다. 결과는 `workspace/delivery/Image-Lab.html`이다. 이 스크립트는 고지 파일을 자동 동봉하지 않으므로 HTML 또는 빌드를 배포할 때 `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`, `licenses/`와 `assets/character/NOTICE.md`를 함께 제공한다. 로컬 모델·편집 데이터를 담는 `workspace/` 전체를 배포하지 않는다.

```sh
node --test tests/image-lab*.test.mjs
npm test
```
